# Contributing

valo-gateway is a public reference enforcement surface, not an authorization or policy engine.

Discussion, issues and conformance scenarios are welcome proposal/evidence surfaces. They are not normative by themselves. Normative enforcement semantics change only through an accepted, versioned change under [`GOVERNANCE.md`](GOVERNANCE.md).

Contributions must be submitted through pull requests and include:

- problem statement and stable issue/proposal reference;
- proposed normative or non-normative change;
- compatibility class: major, minor or patch;
- security impact;
- affected contracts and enforcement behavior;
- required positive/negative conformance cases where behavior changes;
- migration notes where applicable;
- external evidence/references where relevant;
- proposed target version.

Normative language uses MUST, MUST NOT, SHOULD, SHOULD NOT and MAY as defined by RFC 2119 and RFC 8174.

Do not submit private or internal source code, customer credentials, unpublished patent material, internal thresholds or proprietary evaluation logic.

A private implementation or experiment may motivate a public proposal, but implementation existence does not make the proposal normative.
