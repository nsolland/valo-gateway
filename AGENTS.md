# AGENTS.md — public contribution guidance

This repository is a public reference and conformance surface for an execution-boundary component.

Contributors and automated agents should use only the public contracts, source, tests, documentation, and contribution rules contained in this repository.

## Public boundary

- Do not publish or infer private portfolio architecture, private repository relationships, unpublished provider strategy, internal orchestration, research hypotheses, delivery roadmaps, work claims, or branch ownership metadata.
- Keep public documentation focused on the component's externally observable contract and conformance behavior.
- Public adapters and examples must remain vendor-neutral where the published contract requires it.
- Security and non-bypass properties should be demonstrated through public tests without exposing unrelated private implementation context.
- Normative or compatibility changes require review and corresponding public conformance evidence.

See `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, and the public conformance suite for repository-specific requirements.
