# Security policy

The gateway sits on a consequence-bearing enforcement boundary. Do not disclose suspected bypass, replay, permit-consumption or credential-routing vulnerabilities in public issues before a fix is available.

Use GitHub private vulnerability reporting for this repository when available. Include the affected commit/version, exact action path, expected invariant, observed effect and whether an effector was invoked.

High-priority reports include any violation of no-direct-effect-path, null-effect-on-deny, one-shot permit consumption, replay protection, binding continuity or effector-exclusive credential handling.
